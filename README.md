# ProxyLink

Универсальное Android-приложение-прокси. Поднимает `VpnService`, направляет TCP-трафик
через SOCKS5 или HTTP CONNECT, DNS — через DNS-over-TLS, а весь прочий UDP блокирует.

**Это не мод YouTube.** Приложение не патчит и не модифицирует чужие APK, не содержит
ничего с брендом YouTube и спокойно публикуется под своим именем.

## Что умеет

- SOCKS5 (с логином/паролем) и HTTP CONNECT
- автоподключение к заданному прокси после подтверждения VPN системой
- TCP-релей с базовым контролем потока и ретрансмиссией
- DNS через DoT (`1.1.1.1`, SNI `cloudflare-dns.com`) — чтобы запросы не уходили мимо туннеля
- блокировка UDP → YouTube не может уйти в QUIC и переключается на TCP через прокси
- уведомление с кнопкой «Отключить»

## Сборка

Компилятора на телефоне нет, поэтому два варианта.

### Вариант 1: GitHub Actions (проще)

1. Залей папку `ProxyLink` в новый GitHub-репозиторий.
2. В разделе Actions дождись workflow **Build APK**.
3. Скачай артефакт `proxylink-debug`, распакуй — внутри `app-debug.apk`.

### Вариант 2: локально

Нужны Android Studio (SDK 34) и JDK 17:

```sh
gradle assembleDebug
```

APK будет в `app/build/outputs/apk/debug/`.

## Ограничения (важно)

Это **функциональный прототип**, а не production-туннель:

- IPv4 + TCP только. IPv6 не маршрутизируется.
- Реализован упрощённый TCP: нет переупорядочивания сегментов, окно не масштабируется,
  на разрывах возможны обрывы. Для обычного веб-серфинга и стриминга обычно хватает,
  но под высокой потерей пакетов будут артефакты.
- Весь UDP, кроме DNS/53, отбрасывается. Это осознанно: так QUIC не «протекает» мимо
  прокси, но голос/видеозвонки через UDP работать не будут.
- Если нужен надёжный туннель для прода, лучше заменить релей на проверенный движок
  (`sing-tun` / `go-tun2socks`) и оставить этот UI как оболочку.

## Про геоблокировку

Само приложение нейтрально — это обычный VPN-клиент, как десятки других. Но **использование**
прокси для обхода региональных ограничений нарушает ToS YouTube. Это уже зона ответственности
пользователя, а не приложения. Не позиционируй Its как «обход геоблокировок» в описании
магазина — иначе получишь отказ в публикации.

## Публикация

- Не используй названий/иконок YouTube, Google, «YouTube Vanced», «ReVanced» и т.п.
- В Google Play понадобится раскрытие цели `specialUse` для foreground-службы; на F-Droid
  и при прямой раздаче APK это не нужно.
- Открытый исходник и нейтральное описание («универсальный SOCKS/HTTP VPN-клиент») —
  самый безопасный путь.
